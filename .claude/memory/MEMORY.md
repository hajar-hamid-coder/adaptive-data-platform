# Mémoire du projet ADP

Index (une ligne par fichier). Charger au démarrage de session ; mettre à jour en fin de tâche/phase.

- [user-profile.md](user-profile.md) — qui est l'utilisateur, objectifs de candidature, préférences de travail
- [decisions.md](decisions.md) — décisions d'architecture et de produit durables (avec raison)
- [lessons.md](lessons.md) — pièges rencontrés et corrections, à ne pas répéter
- [journal.md](journal.md) — une ligne par tâche terminée, bilan par phase

Règles : ne pas dupliquer ce que `git log`, le code ou `backlog.xlsx` disent déjà ; une décision = une ligne + la raison ; supprimer ce qui devient faux.
